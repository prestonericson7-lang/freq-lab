# vlf_sid — 8-station VLF solar-flare receiver (experiment #19)

US Navy VLF transmitters (NLK, NPM, NAA, NML, ...) send a constant-strength
signal that travels between the ground and the bottom of the ionosphere. When
a solar flare's X-rays hit the daytime sky, that ceiling drops within minutes
and every daytime station you receive jumps or dips by a few dB — a Sudden
Ionospheric Disturbance (SID). This design measures 8 stations at once, every
second (on GPS seconds if a GPS is connected), so the flare shows up as a step
in all of them at the same moment as the NOAA GOES X-ray curve.

The FPGA only listens. Nothing in this design transmits.

## Wiring (JM1)

| JM1 pin | FPGA ball | Signal | Notes |
|---|---|---|---|
| 2 | — | 3.3 V | powers the preamp's output stage |
| 4 | — | GND | |
| 6 | E17 | ANTENNA+ (VAUX1P) | preamp output, **0 to 1.0 V only**, rest at 0.5 V |
| 8 | D18 | ANTENNA− (VAUX1N) | preamp ground, wired at the preamp |
| 14 | B19 | UART TX | to the 3.3 V USB-serial adapter's RX |
| 16 | A20 | UART RX | from the adapter's TX |
| 18 | C20 | GPS PPS | 3.3 V 1PPS from a GPS module (optional) |
| 5 / 7 | H16 / H17 | fan PWM / tach | as in the other designs |

LEDs: R19 blinks at 1 Hz (running). V13 blinks once per finished window and
stays **on** if the last window clipped (antenna signal too big: lower the gain).
KEY1 held = fan 100 %.

## Front end (what goes between the antenna and JM1-6)

```
 loop antenna  -->  preamp ~60 dB, 10-50 kHz  -->  0.5 V bias  -->  100 ohm  -->  JM1-6
 (1 m square,       (low-noise rail-to-rail                          + 2.2 nF
  ~10 turns)         op-amp on the 3.3 V pin)                         to JM1-8
```

* A **loop** (1 m square frame, about 10 turns of insulated wire) picks up the
  magnetic field and ignores much of the house's electric noise. It is
  directional: its edge points at the stations it hears best.
* Run the preamp's last stage from **JM1-2 (3.3 V)**: then nothing it can do
  can put more than 3.3 V on the pin. Above 1.0 V the ADC just reads full
  scale (the LED tells you).
* The preamp must roll off above ~60 kHz (the ADC samples at 390.6 kS/s, so AM
  broadcast stations would otherwise fold down into the band) and below ~10 kHz
  (60 Hz mains harmonics).
* Outdoors, keep the antenna away from switching power supplies, LED lights and
  the house wiring, and disconnect it when there is thunder around.

`vlf_host.py level` shows the input level once a second while you set the gain
(aim for 30–300 counts RMS, zero clipping). `vlf_host.py scan` then draws the
10–50 kHz spectrum in about ten seconds and names the stations it finds.

## Build and load

1. Double-click `fpga\build_vlf_sid.bat` (about 5 minutes). Result:
   `fpga\vlf_sid\build\vlf_sid.bit`, reports in `fpga\vlf_sid\build\`.
2. Board on USB-JTAG, open the **Vivado Tcl Shell**:
   ```
   cd P:/Downloads/freq-lab/fpga/vlf_sid
   source program.tcl
   ```
   This loads RAM only; a power cycle puts the board back exactly as it was.

## Use (PC, `pip install pyserial matplotlib`)

```
python tools/vlf_host.py COM7 info            # status, sample rate, all 8 stations now
python tools/vlf_host.py COM7 level           # set the preamp gain with this
python tools/vlf_host.py COM7 scan            # 10-50 kHz spectrum, names the peaks
python tools/vlf_host.py COM7 log --goes      # 1 line per second to vlf_YYYY-MM-DD.csv (+ GOES X-rays)
python tools/vlf_host.py plot vlf_2026-10-02.csv --goes goes_2026-10-02.csv
python tools/vlf_host.py COM7 tune 7 23.4     # move channel 7 to another station
```

Default channels: NLK 24.8, NPM 21.4, NAA 24.0, NML 25.2, NAU 40.75, NWC 19.8,
JJI 22.2 kHz and a 30.0 kHz empty reference (noise and lightning).

What a flare looks like: during daylight on the signal path, a C-, M- or
X-class flare (GOES curve) is matched within minutes by a step of a few dB in
the daytime stations, then a recovery over 30–90 minutes. Sunrise and sunset
produce big, slow, daily-repeating swings; flares are the sudden ones that line
up with GOES.

## Design numbers

* XADC VAUX1, 12 bit, 390,625 S/s (50 MHz / 4 ADC clock, 32 clocks per
  conversion). The FPGA measures its own sample rate (register 1A) and the host
  tunes with the measured value; with GPS it also corrects the crystal (±50 ppm).
* Each channel: 32-bit NCO (0.09 mHz steps), 12-bit-phase sine (spurs about
  −72 dBc), 12×16 mixer, 3-stage CIC decimating 1024× (381 outputs/s), 57-bit
  registers (cannot overflow), rounded to 24-bit I/Q.
* Channel shape: −0.7 dB at ±50 Hz, −3 dB at ±100 Hz, −80 dB at ±400 Hz (the
  usual station spacing), sidelobes below −40 dB. A 200-baud MSK station reads
  0.6 dB below its full power; 400 Hz away you still see −33 dB of its own
  spectrum (that is really there, not filter leakage).
* Per window and channel: Σ(I²+Q²) and the largest single I²+Q² (lightning
  sferics), plus input RMS, DC, min/max and clipped-sample count.
* A tone of A ADC counts reads `sqrt(POW/NDEC) = A × 2047.94`.

## Verification (simulation, Icarus Verilog)

```
cd fpga/vlf_sid
python3 sim/gen_files.py
iverilog -DSIMULATION -o sim/tb_vlf sim/tb_vlf.v hdl/*.v
cd sim && vvp tb_vlf && python3 check_vlf.py
```

Stimulus: a 100-count 200-baud MSK station at 24.8 kHz, a 20-count tone at
21.4 kHz, a 300-count tone 400 Hz from the 24.0 kHz channel, ±3-count noise,
a clipping burst, and a fake GPS PPS. Results:

* testbench: 33/33 register, protocol, PPS, window and snapshot checks pass;
* every decimated I/Q value of all 8 channels is identical to a bit-exact
  Python model, and every window sum and register read matches;
* the fixed-point receiver agrees with an ideal floating-point receiver within
  0.003 dB; the 20-count tone reads 20.01; the 400 Hz-off 300-count tone is
  rejected by 80 dB; the channel response matches the CIC formula to 0.001 dB.

Vivado 2026.1 (xc7z020clg400-2, Oct 1 2026): builds in about 6 minutes, exit
code 0, 0 critical warnings. Timing met at 50 MHz: setup slack +6.3 ns, hold
+0.036 ns, 0 failing of 44,858 endpoints. 9,142 LUTs (17 %), 14,028 flip-flops
(13 %), 50 DSPs (23 %), 4.5 block-RAM tiles. Every pin placed as in the table
above at LVCMOS33. Estimated power 0.15 W, junction 26.7 °C. Not yet run on
hardware.

## Register map (UART, 115200 8N1, `R aa` / `W aa dddddddd`)

| Addr | Name | | |
|---|---|---|---|
| 00 | ID | RO | 0x564C0001 |
| 01 | CTRL | RW | bit0 RUN, bit1 PPS_MODE (default 3) |
| 02 | WIN | RW | window length in samples without PPS (default 390625) |
| 03 | STATUS | RO | 31:16 window count; bit3 PPS alive; bit2 last window timed out; bit1 last window ended on PPS; bit0 RUN. **Reading it freezes the last window into 04–0D and 20–3F.** |
| 04 | SEQ | RO | window number of the frozen copy |
| 05 | NSAMP | RO | samples in the window |
| 06 | NDEC | RO | outputs per channel in the window |
| 07 | FLAGS | RO | bit0 ended on PPS, bit1 started on PPS, bit2 timed out |
| 08 | CLIP | RO | samples at code 0 or 4095 |
| 09 | XMINMAX | RO | {max code, min code} |
| 0A/0B | SQ | RO | Σ(code−2048)², 64 bit |
| 0C/0D | SUM | RO | Σ(code−2048), signed 64 bit |
| 0E | ADC | RO | live code |
| 0F | PPS_CNT | RO | PPS edges since power-up |
| 10–17 | FTW0–7 | RW | channel frequency = FTW × fs / 2³² |
| 18 | FAN_DUTY | RW | % (default 60) |
| 19 | FAN_RPM | RO | |
| 1A | FS_CLKS | RO | 50 MHz clocks per 65536 samples (8388608 = 390625 S/s) |
| 20+4k | POW_LO(k) | RO | channel k Σ(I²+Q²) low word |
| 21+4k | POW_HI(k) | RO | high word |
| 22+4k | PMAX(k) | RO | largest I²+Q² in the window, bits 47:16 |

Replies are queued (512-byte FIFO), so a batch of reads can be sent at once;
`vlf_host.py` reads a whole window in one USB round trip.
